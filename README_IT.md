# 👋 Ciao, sono Fabio Vittori

**Appassionato di Home Assistant e sviluppatore open source · Italia 🇮🇹**

Realizzo dashboard, integrazioni e strumenti pratici e curati per **Home Assistant**: dalla gestione quotidiana della casa intelligente al monitoraggio energetico, alla ricarica dell'auto elettrica e all'organizzazione domestica.

| Progetto | Descrizione | Repository |

| 🏡 **Casa Dashboard** | Dashboard moderna e personalizzabile per la casa intelligente. | [Scopri →](https://github.com/fabiovit/casa-dashboard) |
